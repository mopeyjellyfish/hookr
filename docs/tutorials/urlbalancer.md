# Build A Host And Plugin With FlatBuffers

This tutorial teaches the full Hookr workflow using the `urlbalancer` fixture.

You will:

1. define a FlatBuffers contract
2. generate Hookr glue
3. implement a TinyGo plugin
4. build the plugin
5. implement a host
6. call plugin methods and host callbacks

Use this after the `textfilter` tutorial if you want the first callback-driven
integration path.
