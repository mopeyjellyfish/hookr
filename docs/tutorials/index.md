# Tutorials

Tutorials are learning-oriented. Follow them in order to understand Hookr by
building real working flows.

## Recommended Path

1. [Build A Minimal Plugin With TextFilter Fixture](./textfilter.md)
2. [Build A Host And Plugin With FlatBuffers](./urlbalancer.md)

## What You Will Learn

- how contracts are defined in FlatBuffers
- how `hookr gen` and `hookr build` fit together
- how generated host SDK and plugin PDK APIs are used
- how plugin-to-host callbacks work
